# RetailStream — End-to-End Retail Data Engineering Platform

RetailStream is a production-style local data engineering platform built to process retail batch and streaming data.

## Technology Stack

- Python
- SQL
- PySpark
- Apache Airflow
- Apache Kafka
- PySpark Structured Streaming
- MinIO
- PostgreSQL
- dbt
- Great Expectations
- Docker
- pytest
- GitHub Actions
- Power BI

## Architecture

Batch and streaming retail data will be processed through a local data lake and warehouse architecture.
